## Local gates

`python -B harness/desktop_gate.py --profile core` checks the first PC's sibling source/context and synthetic behavior without academy, Sheet, or remote writes. A fresh clone instead uses the focused workbench tests, backend-map validator, and source-import verifier in the portable guide. `--profile live` additionally needs the checkout's declared optional reader environment; it does not establish live authentication or production acceptance. Read the runner and selected profile when changing its effects or dependencies.

The backend map owns canonical operation counts and route definitions. Use the exact current registry entry rather than a count copied into another document. `safe_to_probe=true` for a fixed page shell does not authorize a parameterized student search.

Historical worktree test counts, Python patch versions, backend read aggregates, remote hashes, and Browser/Computer receipts remain in their dated evidence. New sessions must obtain fresh evidence for the claim they need. Keep immutable transition and source-map material at its pinned paths unless a reviewed migration updates and verifies every consumer.
