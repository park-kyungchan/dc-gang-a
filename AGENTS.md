Run `bun run harness/resume.ts --json` and read `handoffs/current-state.json` for the active phase and latest evidence; fail if that index is missing or stale. - Routine assigned local files, execution, and network work may proceed. Confirm deployment, sending, deletion, and account/access changes unless the exact action is already authorized. The user requests structural improvement, including related local SPT/runtime material, with concrete review before moving, retiring, or deleting operational material.

## Deterministic Entity & Route Queries (Zero-Grep Invariant)

- DO NOT scan directories, grep raw HTML dumps, or run background tasks to discover student IDs, class groups, or LMS backend routes. Execute `bun run harness roster` or `bun run harness routes` (or Python equivalent `python -B harness/cli.py ...`) for instant (<50ms) deterministic results.
- Single Source of Truth: Query the current cohort and class groups from `data/canonical/canonical_roster.json` through the harness, and canonical LMS operations from `research/backend-map/route-registry.json`. Do not rely on a count or name list copied into agent instructions; run `harness verify` for current counts.
- Fail-Closed Safety: Unknown student or route queries immediately exit with code 1; mutating GET endpoints (`day_record_udtprg`, `similar_paper_create`, etc.) are strictly blocked from read probing.
- Dual-Runtime Parity: Identical subcommands (`roster`, `routes`, `verify`), flags (`--id`, `--student`, `--group`, `--category`, `--safe-only`, `--all`, `--json`), and machine-readable JSON payloads are supported under both Bun (`bun run harness ...`) and Python 3.12 (`python -B harness/cli.py ...`).

Preserve the existing dual-runtime `roster`/`routes`/`verify` compatibility contract until its consumers are explicitly migrated.

Preserve existing evidence and handoff files in place unless a reviewed migration updates their consumers.

Read its current effect/reference map before changing it. Use `--profile live` only with that checkout's declared, installed, and locked optional reader environment.
